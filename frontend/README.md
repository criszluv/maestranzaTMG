# Frontend — Portal MaestranzaTMG

SPA en React 19 + TypeScript + Vite. La documentación completa del proyecto
(arquitectura, módulos, seguridad y puesta en marcha) está en el
[README de la raíz](../README.md).

```bash
npm install       # primera vez
npm run dev       # http://localhost:5173
npm run lint      # ESLint
npm run build     # tsc + build de producción (frontend/dist)
```
